# サンエイツール ポータル試作（検証用）

DXメンバーに共有する前に、ポータル方式で「実機でしか分からないこと」を確かめるための試作です。
中身はすべて架空のデータです（名前・接続先とも）。

## 構成

```
index.html              ポータル（名前選択・ツール一覧・設定リンク・確認チェックリスト）
manifest.webmanifest    ポータルをアプリとしてインストールするための設定
tools.js                ツール台帳（ここに1件足すとポータルに表示される）
sw.js                   インストールに必要なサービスワーカー（常に最新を取得）
common/sanei.js         共通スクリプト（利用者名・接続先設定・診断表示）
common/style.css        共通の見た目
icons/                  アイコン（P=ポータル、C=テスト計算、M=テストメモ）
tools/calc/             テスト計算（単独インストールも可能）
tools/memo/             テストメモ（単独インストールも可能）
```

## 公開手順（GitHub Pages）

1. GitHubで新しいリポジトリ `sanei-portal-test` を **Public** で作る
   （無料プランのPagesは公開リポジトリのみ。試作なので個人アカウントで可）
2. 「uploading an existing file」から、このフォルダの**中身**をまとめてドラッグして「Commit changes」
3. Settings → Pages → Source「Deploy from a branch」→ Branch `main` / `(root)` → Save
4. 1〜2分後に `https://<アカウント名>.github.io/sanei-portal-test/` で開ける

## 確認のしかた

ポータルを開き、ページ内の「確認チェックリスト」に沿って確認する。
各画面の下にある黄色い「診断情報」で、表示モード（アプリのウィンドウか、Chromeのタブか）や
利用者名・接続先設定の状態が分かる。終わったら「結果をまとめてコピー」で結果を貼り付ける。

## 試作の後始末

検証が終わったら、Chromeでインストールした試作アプリをアンインストールし、
リポジトリを削除（または非公開に）する。
