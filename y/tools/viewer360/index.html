360度写真ビューア

写真ファイル（1枚でも複数でも）かフォルダを、ここへドラッグ＆ドロップしてください。JPEG / PNG / WebP / BMP と、Insta360の .insp（静止画）に対応します。

［フォルダを開く］の画面では、フォルダの中の写真は表示されません。写真の入ったフォルダを選んで決定してください。

一度開いたフォルダは記憶されます。次からは、その中の写真を1枚ドロップするだけで前後の写真も読み込めます。

操作がわからないときは、写真を開いたあと上部の［操作方法］を押してください。

操作方法

写真を送る
画面の左右端をクリック前の写真 / 次の写真（Ctrl + ← → でも可）
下の一覧をクリックその写真へ移動
［一覧］ボタン大きなアイコンで一覧表示。☆で お気に入り切替
見る向き・拡大
ドラッグ視点を回す（全体表示では画像を動かす）。十字キーでも可
ホイール拡大・縮小（右下の ＋ − でも可）
ダブルクリック全体表示 → その場所を360で見る / 360 → 全体表示に戻る
右下の ⟲向きと拡大を元に戻す
［360°］［全体］ぐるっと見る表示と、平面の展開図を切替（V キーでも可）
並べて見る
［分割］左右2画面で別々の写真を見る。操作するのは青枠の側（クリックか Tab で切替）
お気に入り・フォルダ
☆ ボタンお気に入りを付ける / 外す（F キーでも可）
［お気に入りのみ］お気に入りだけ表示（G キーでも可）
［🏠 ホーム］最初の画面へ。前回のフォルダから開き直せる
写真を1枚ドロップ一度開いたフォルダなら、同じフォルダの写真もまとめて読み込む
［✎ メモ］フォルダに処理場名などのメモを付ける
